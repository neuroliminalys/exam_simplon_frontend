# USER STORIES BACKLOG

## Not connected users (visitors)

- "As a visitor, I want to see all museums, to get an idea of what I want to visit"
- "As a visitor, I want to search a museum by name, to get the details of a museum that interests me"
- "As a visitor, I want to search a museum by town, to be able to search only those who are near me"
- "As a visitor, I want to search a museum by domain, because I'm not interested in all domains"
- "As a visitor, I want to get the details of a museum, to know it's schedule, etc"
- "As a visitor, I want to get a detailed guide of the museum, so I can preview the roadmap and the accessibility of it"

## Connected users

- "As a connected user, I want to be able to favorite a museum, so I can compare and find again each easily"

## Admins

- "As an admin, I want to create a museum, to register on the website a new (temporary) museum that opened"
- "As an admin, I want to be able to modify museum informations, to always maintain up-to-date infos"
